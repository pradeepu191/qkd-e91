1 · Calibration sweep

Park Alice's motor at the specified angle, sweep Bob's HWP, record counts on the selected channel.

Random bases (3 angles, 120° apart) and bits (0 or 1 → +90°) for Alice and Bob.

3 · Run QKD experiment

For each pair (ai, bi) rotate HWPs, wait for motion to finish, average N samples on the chosen channel.

6 · Modified E91 (probabilistic sift)

For each trial, accept it as a "logical coincidence" with probability p = (n − nmin) / (nmax − nmin), where n is that trial's coincidence count. nmin defaults to the calibration's trough (C − A, counts at 90° relative angle); nmax defaults to the peak (A + C). Override below if needed.
